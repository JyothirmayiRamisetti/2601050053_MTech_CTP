Description
This project contains a Python script that implements a Student Attendance System. It calculates individual attendance percentages, identifies students falling below a required 75% threshold, determines the highest and lowest attendances, and computes the overall class average.

Algorithm
The core logic of the system follows this step-by-step algorithm:

Start
Get Student Data: Retrieve the attendance records for the students.
Calculate Percentages: Compute the attendance percentage for each individual student.
Check Threshold: Check if there are students with an attendance percentage strictly below 75%.
Find Extremes:
Identify the student with the highest attendance (topper).
Identify the student with the lowest attendance.
Calculate Class Average: Compute the mean attendance percentage across all students.
Display Report: Print the final formatted report with all the calculated statistics.
